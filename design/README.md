# Design sources

Master SVGs for all original artwork. Convert to VectorDrawable for the app; never edit the
generated XML by hand.

- `sigils/` — one hero sigil per hero id (24-unit grid, 2-unit stroke).
- `icons/` — UI icons not covered by Material Symbols.
- `avatars/` — player crests.
- `brand/` — app icon layers, wordmark.

See `../docs/DESIGN.md` for the asset policy.
